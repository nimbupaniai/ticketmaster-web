## Project

Event discovery and ticketing platform for fans, artists, venues, and organizers. It lets users search events, choose seats, purchase tickets, and access mobile entry passes. Verified resale and organizer tools set it apart from basic ticketing services.

**Stack:** React, React Native, TypeScript, Node.js, GraphQL, PostgreSQL, Redis, AWS, Stripe, Kafka

## This repository

Web app for fans to discover events and buy tickets.

## Related repositories

- `ticketmaster-mobile` — Mobile app for fans to access digital tickets and buy on the go.
- `ticketmaster-catalog` — Service that owns event, venue, and artist data.
- `ticketmaster-orders` — Service that owns carts, payments, and orders.
- `ticketmaster-ticketing` — Service that issues and validates digital tickets.
- `ticketmaster-organizer` — Dashboard for event organizers and venues.
